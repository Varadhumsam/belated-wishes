BELETED BIRTHDAY SURPRISE WEBSITE

FILES
- index.html: opening page
- game.html: question game
- letter.html: personal birthday letter
- final.html: final surprise
- style.css: shared design and animations
- script.js: game logic and confetti

TEST LOCALLY
1. Open the BelatedWishes folder in VS Code.
2. Open index.html in your browser (or use the Live Server extension).
3. Click through every page and test the answer game and final button.

CUSTOMIZE
- Edit the text in letter.html and final.html.
- Replace "Pattamboochi" with her nickname if you want.
- To add photos, create an images folder and use: <img src="images/photo1.jpg" alt="Our memory">
- This starter project does not include music; add music only if you have a file you are allowed to use and test playback after a user click.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository, e.g. belated-wishes (public is simplest).
2. Upload all six files to the repository root (not inside another folder).
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for the Pages URL to appear. It will look like https://YOUR-USERNAME.github.io/belated-wishes/
7. Open the URL and test each page. All filenames and links are lowercase and relative, so the pages work from a GitHub project URL.

NOTE: The question is a playful front-end gate, not secure access control. Anyone can open the pages directly if they know their URLs.
